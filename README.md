# 🌸 Yasso Hand Maid (الأتيليه الزجاجي)

أتيليه إلكتروني فاخر وتفاعلي لعرض وطلب مستلزمات الأفراح والمناسبات المصممة يدوياً من الأكريليك، اللؤلؤ، المطرزات، وجرابات الهواتف الفاخرة للبراند المصري **ياسو هاند ميد (Yasoo Handmade)**.

الموقع مصمم كصندوق مجوهرات رقمي فاخر بلمسات وتفاصيل بصرية راقية مع تركيز فائق على الأداء والانسيابية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

1. **الأساس (Core):** React 19 + Vite 8
2. **المؤثرات الحركية (Motion):**
   * **GSAP + ScrollTrigger:** لتأثيرات السكرول ومسار الخيط الذهبي.
   * **Framer Motion:** للحركات الانتقالية الناعمة وفتح المودال ثلاثي الأبعاد.
3. **العناصر ثلاثية الأبعاد (3D Rendering):**
   * **React Three Fiber (R3F) + Three.js:** لتأثير اللآلئ العائمة ومجال النجوم التفاعلي بالخلفية.
4. **السكرول الانسيابي (Smooth Scroll):**
   * **Lenis Scroll:** لسكرول ناعم يحاكي فخامة البراند.
5. **التصميم والتنسيق:** Vanilla CSS (سريع، خفيف، ومتوافق بالكامل مع RTL).
6. **الاختبارات (Testing):**
   * **Vitest + React Testing Library + jsdom:** لاختبارات الجودة وصحة توليد الروابط التفاعلية للفورم.

---

## 📱 التجاوبية ودعم الأجهزة المختلفة (Responsive & Mobile-Ready)

* **GSAP matchMedia:** تم فصل الحركات وتأثيرات تجمع الزجاج وتمدد الخط الزمني أوتوماتيكياً بين شاشات الموبايل والكمبيوتر لتقديم أفضل تجربة لكل جهاز.
* **ResponsiveCamera (Three.js):** الكاميرا تعيد حساب زاوية الرؤية (FOV) ومسافة البعد Z تلقائياً بناءً على نسبة أبعاد الشاشة (Aspect Ratio) لمنع خروج اللآلئ عن مساحة العرض على شاشات الهواتف الطولية.
* **دعم اللمس (Touch Devices):** تم إلغاء تأثيرات تتبع الماوس (Parallax) تلقائياً على شاشات اللمس لمنع القفزات والحفاظ على استقرار الأداء.
* **عزل السكرول في المودال (Lenis Prevent):** استخدام سمة `data-lenis-prevent` وقفل السكرول البرمجي يضمن إمكانية تصفح معارض الصور ولمسها بمرونة على الموبايل والتابلت دون تحرك الصفحة الخلفية.

## 🚀 التشغيل والاختبار محلياً (Local Development)

### ١. تثبيت الاعتماديات
```bash
npm install
```

### ٢. تشغيل خادم التطوير المحلي
```bash
npm run dev
```
افتح الرابط المحلي [http://localhost:5173](http://localhost:5173) في متصفحك.

### ٣. تشغيل الاختبارات للتأكد من جودة الأكواد
```bash
npm run test
```

### ٤. بناء نسخة الإنتاج النهائية (Build)
```bash
npm run build
```
تُنتج هذه العملية ملفات مضغوطة ومحسنة كلياً داخل مجلد `dist/` جاهزة للنشر.

## 🌐 النشر والرفع (Deployment on Vercel)

المشروع مهيأ بالكامل للنشر الفوري على منصة **Vercel** أو **Netlify** باستخدام الإعدادات القياسية لـ Vite:

* **Build Command:** `npm run build`
* **Output Directory:** `dist`
* **Node.js Version:** 18 أو أعلى

*لا يتطلب المشروع أي متغيرات بيئة (Environment Variables) خارجية أو قواعد بيانات للتسهيل الكلي في إدارة المحتوى وحفظ خصوصية الرسائل المباشرة عبر واتساب.*
